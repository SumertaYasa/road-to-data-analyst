# Road to Data Analyst

Folder ini dan seluruh isinya merupakan perjalanan saya untuk switch career menjadi seorang data analyst. Saya akan selalu memegang teguh bahwa _belajar dan memahami funamental_ akan membuat seseorang menjadi apa yang ia inginkan di suatu hari nanti.

Saya akan menampilkan apa yang saja pelajari walaupun cara penulisan saya kurang enak dibaca maupun dipelajari karena balik lagi folder ini merupakan perjalanan saya. Berharap dari semua hal ini bisa membantu memberikan sudut pandang baru dalam proses belajar.

quote:

> "Terlihat bodoh di awal tidak berakhir menjadi bodoh selamanya. Kenali dirimu, cari metodemu, dan eksekusi apa yang kamu inginkan."

## Struktur Direktori

- **`1_Python_Programming/`**: Fundamental Python, OOP, dan fondasi _Web Scraping_.
- **`2_SQL_Databases/`**: Dasar hingga lanjutan SQL (CTEs, Window Functions) untuk manajemen _database_.
- **`3_Data_Processing_and_EDA/`**: Manipulasi dan pembersihan data menggunakan Pandas dan NumPy.
- **`4_Data_Visualization/`**: Ekstraksi _insight_ menggunakan Matplotlib, Seaborn, dan _Dashboarding_ (Tableau/PowerBI).
- **`5_Google_Data_Analytics_Cert/`**: Catatan dan tugas dari sertifikasi resmi Google.
- **`6_Portfolio_Projects/`**: Proyek nyata (_End-to-End_) untuk _showcase_.
- **`7_Theory_and_Math/`**: Teori statistika dan metrik bisnis (KPI, A/B Testing).
- **`8_Resources/`**: _Cheatsheets_, tautan berguna, dan dokumentasi.

## Filosofi Belajar

Perjalanan transisi ini didukung oleh komitmen pada tiga pilar utama:

1. **Learning:** Terus mencari tahu bagaimana memproses data mentah hingga menjadi informasi yang memvalidasi sebuah fakta.
2. **Earning:** Membangun _skill_ teknis yang solid untuk membuka peluang karir sebagai Data Analyst profesional.
3. **Health:** Menjaga ritme dan metode belajar yang sehat agar proses eksekusi tetap konsisten.
